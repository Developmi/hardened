# NIST SP 800-171 - Controlled Unclassified Information

Mapping of NIST SP 800-171 controls for protecting Controlled Unclassified Information (CUI) in non-federal systems is **not yet implemented**.

## Overlap with NIST SP 800-53

Several NIST SP 800-171 security requirement families overlap with already-implemented NIST SP 800-53 controls:

| 800-171 Family                       | Overlapping 800-53 Controls | Status                                             |
| ------------------------------------ | --------------------------- | -------------------------------------------------- |
| Access Control                       | AC-2                        | Implemented - see [NIST_800_53.md](NIST_800_53.md) |
| Configuration Management             | CM-7                        | Implemented - see [NIST_800_53.md](NIST_800_53.md) |
| System and Communications Protection | SC-7                        | Implemented - see [NIST_800_53.md](NIST_800_53.md) |
| System and Information Integrity     | SI-4                        | Implemented - see [NIST_800_53.md](NIST_800_53.md) |
| Audit and Accountability             | AU-12                       | Implemented - see [NIST_800_53.md](NIST_800_53.md) |

A formal 1:1 mapping between 800-171 controls and Ansible role implementations is planned for a future release.

Reference:

- [NIST SP 800-171 Rev 3](https://csrc.nist.gov/pubs/sp/800/171/r3/final)
